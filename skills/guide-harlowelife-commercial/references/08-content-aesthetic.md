# 宣传、内容与中英文审美

## 一条内容只完成一个任务

内容顺序：**具体痛点/生活时刻 → 看得见的动作与变化 → 用户利益 → 足够证据 → 一个下一步。**
科普与光谱属于证明层，不占满开场。让观众先看懂，再产生向往。[S02/S11/C01]
人物投入工作、画册、创作、音乐与关系；安静空间里仍有活力。不要默认成熟人群只会喝茶、闭眼或被动疗愈。

## 可用钩子：作为创作工作稿测试

| 场景 | 开场 | 画面必须证明 |
|---|---|---|
| 桌前工作 | 一张桌子，从早到晚，为什么只用一种光？ | 同一位置的任务与时间变化 |
| 环境变化 | 房间很亮，手边却未必有合适的光。 | 真实任务位置，不伪造曝光 |
| 任务结束 | 工作到晚上，光可以先暖下来。 | 真实操作、光色与任务，不演立即治愈 |
| 夜间取水 | 夜里只想取杯水，需要把房间都照亮吗？ | 推荐低档的可见动作，避免误示绝对无干扰 |
| 家居购买 | 一盏灯好看，还要知道它陪你做什么。 | 尺度、形态和实际用途 |

疲劳、昏沉、起不来、晚睡等能引发共鸣，但解释要承认多种原因。不能把所有症状诊断为缺光或让消费者以为买灯即可解决。

## PDP与官网模块

1. 首屏：真实产品、一个明确场景/利益、一个主CTA；价格与可售状态在购买意图形成处清楚可见。
2. 用在哪里：人、桌面/床头/边柜、真实比例与任务。
3. 如何工作：用户所选任务、传感器位置、时间或实体操作，限当前功能。
4. 证据：一图一结论，完整条件；数据热图与源端/眼位分层。
5. 比较与选型：具体型号、适配场景和局限；不只比参数数量。
6. 规格、操作依赖、安装、尺寸、价格、交付、保修、退换与FAQ。

消费者页面不放内部缩写HPIE/PEI、未冻结BOM、研发审批过程或“待验收”标签。必要未定项用准确商品状态呈现。品牌故事不代替产品。

## 上市主广告当前工作方法

S11为2026-11-10的75秒工作稿，另有60秒及30秒版本。参考Eight Sleep的用途清晰、Oura的人生活力、Apple的感官叙事，不复制trade dress或借用功效。

| 产品 | 自然出现的情节关系 |
|---|---|
| Desk | 屏幕切纸面，手选任务与实际光 |
| Floor | 离桌阅读、画册或创作 |
| Halo | 晨间/夜间床边的创意工作稿 |
| Halo Plus | 晚间个人角落收光 |
| Halo Sound | 声源启动、音乐展开、人与人相处 |
| VELA | 边柜真实选香/扩香 |
| MORA | 随行物件到手边的近身温香 |

**场景冲突**：10月美国手册明确小Halo用客厅、Plus/Sound用床头；11月主片工作稿小Halo床边不自动覆盖地区选型。美国版床头镜头优先沿对应商品定位，未厘清时用Plus/Sound。
七类主片与CES七款各自按任务定义，不宣称一一对应。

每个重要镜头遵循：人在做事→手如何操作/真实触发→环境变化→人继续生活。无实机验证的自动变化拍为真实手动操作，不虚构语音控制、任务识别、人体监测或跨设备联动。
75秒主片中Desk、Halo Sound承担较完整情节，其他产品用一个清楚动作交代，不平均每件背参数。
建议验收：请未参与项目的人看一遍后复述产品作用和想拥有的时刻。若只记住房间或只记住技术，调整因果和人物停留。样本与通过数是制作建议，不冒充消费者调研。

## 中文审美

宋代审美作为比例与秩序：纸、墨、石、木、瓷、茶、苔；天青/烟霞、深绿、少量朱砂红；古意进入材质和尺度，不靠古画贴图、卷轴边框、书法堆砌。
宋体表达气质，黑体承接操作/参数；留白分组，模块内部可紧凑，不做巨大空屏与超大标题。朱红印记少量且有识别作用。
日内色彩变化Chromatic Rhythm应来自真实光与时间，不用无规律高饱和色块代替内容。

## 英文审美

quiet、architectural、tactile、editorial、contemporary，保持商业清晰。学Aesop的文字与材质秩序、Aman的空间平静，不复制它们字体、版式和摄影公式。
衬线承担编辑气质，无衬线承担导航/规格。真实工作、家居与人是主角，不以通用米色高级模板抹掉光与时间的识别。
按英文购买逻辑重写，不直译中文文化隐喻。克制不是低对比、微小字、无CTA或慢交互；保持45–65岁读者可读。

## 图片与技术图真实性

- 冻结产品只用实拍、官方3D、冻结资产或严格保形合成，不生成重画灯头、音响、雷达位置、关节或比例。
- Ritual实物发光面以真实手板为准，雷达位置与金属/布面按当前设计；不擅自恢复不可保留黄铜效果。
- 人物与家具要匹配产品品质；Ritual等床头设备不要被放大成巨物。
- 强调夜间用途时，外部日光不应充足到产品无实际作用。
- 比较画面锁定曝光、白平衡、机位、背景。审美图可以调色，但不能冒充性能对照。
- 不生成虚假光谱、照度、雷达环、AI健康分数或烟雾粒子表示真实扩香。
- 未获授权作品、肖像、音乐及活动照片不可因“内部有图”就随意改图和传播。

## 内容迭代

先看用户能否理解与停留，再看有效线索和成交。对弱表现先区分钩子、形式、画面证据、受众与分发，不能只把科普讲得更多。创始人故事用于增强可信与共鸣，不压过用户问题。所有新标题/门槛均是测试稿，不冒充已验证爆款。
