# 潜在用户与购买任务

## 人群状态

35–55岁高绩效成年人是近期聚焦；早期材料有35–60岁，审美可读性还需照顾45–65岁。这些是优先画像，不是拒绝其他年龄，也不是已验证购买者分布。[S01/S03/C04]
不要把“企业家、高知、高净值”当作已完成市场细分；用行为、场景、触发、替代品和支付行为选用户。

| 人群假设 | 真实问题/触发 | 产品切入 | 需取得的证据 |
|---|---|---|---|
| 长时间室内工作的专业人士 | 屏幕、文件、精细任务切换；自然光改变；晚间仍需工作 | Desk；Floor按实际位置 | 现有灯不足在哪里、任务使用与摆位、真实价格反应 |
| 40+深度阅读与创作者 | 阅读光需求发生变化，仍重视工作与兴趣 | Desk/Floor | 使用任务、照明需求与主观感受；不用“老年灯”标签 |
| 重视家居设计的人 | 正在买台灯/落地灯，希望器物与空间相配且好用 | Halo类或SOLA | 尺度、材质、关闭与点亮状态、实际购买比较 |
| 关注晚间环境的人 | 晚上家里过亮；需要取水/起身；不愿反复开App | 对应Halo类 | 低亮启动、控制、推荐位置与真实夜间眼位 |
| 想减少床头设备的人 | 灯与音响占位置，重视声音和设计 | Halo Sound；Ritual具体型号另核 | 实际音质、控制、设备替代价值与地区可售 |
| 住宅/精品空间设计师 | 需要可解释、可安装、可维护的功能灯 | 单位置或房间试点 | 规格、样品、项目预算、安装售后与推荐意愿 |
| 已用可穿戴或高端人体工学设备的人 | 已投入管理状态，可能愿意进一步管理环境 | 工作位/晚间位 | 这是行为邻近性，不是合作、数据互通或必然转化 |

## 用户痛点如何表达

| 可切入的日常描述 | 不应自动推导 |
|---|---|
| 房间很亮，工作位置却未必合适 | 所有疲劳都由照明造成 |
| 同一个位置从白天用到深夜，光一直没变 | 改灯必然改善失眠 |
| 家中虽有智能场景，白天到夜晚仍要自己处理 | 智能系统都没有影院/日落/自动化模式 |
| 看屏幕、纸面和细节需要不同安排 | 灯已自动识别正在做什么 |
| 想要好看的灯，也想知道它实际怎么用 | 设计灯都只有装饰作用 |
| 想保留装修整体风格 | 所有家庭都能换灯泡或做无风险改造 |

早老花是创始人可选择分享的内容背景，不作为团队自行披露的私人病史，也不推导“治疗老花”。表达对成年人视觉需求的关注，不制造衰老羞耻或年龄焦虑。

## 三类购买任务

- 功能：在实际位置看清、完成任务，按时间调整，降低操作负担。
- 感受：空间成熟、安静、舒适、有材质，不像儿童学习设备或电竞设备。
- 身份：认真照顾自己的日常环境，保有兴趣与生活主动权。

卖点按一个具体任务排序，不把所有痛点和技术一次讲完。办公用户先证明任务光；晚间用户先证明光与操作；设计用户先证明形态、尺度和场景。对声音或香气进入的用户，也允许独立购买，不强迫先认同照明理论。

## 访谈与验证

先问过去的行为，再展示产品，最后展示真实价格：
1. 最近一次买灯/改工作区发生在何时，为什么？
2. 现在最不满意什么，如何解决，为此花过多少？
3. 这款放哪里、替代什么？让用户自己说，不提示术语。
4. 知道价格、交期和售后后，愿意采取什么下一步？
5. 若不买，最主要缺需求、外观、证据、操作、信任还是价格？

分开记录演员、借测者、付费消费者、熟人、设计师和渠道买方。小样本体验适合发现问题与语言，不适合宣布目标市场已被验证。称赞、留资、预约、订金、订单、收货与留用是不同证据。
