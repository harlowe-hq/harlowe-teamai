# 技术要求与数据解释

依据S04/S05/S06；为商业团队解释数据，不是医疗使用建议或整套认证标准。

## 指标必须各归其位

| 指标 | 说明什么 | 不能据此说什么 |
|---|---|---|
| 光通量lm | 灯具总体可见光度输出 | 用户桌面或眼位一定得到多少lx |
| 普通照度lx | 指定平面、位置及方向的明视觉照度 | 即是节律输入、舒适度或健康效果 |
| CCT K | 接近白光轨迹时的相关色温 | 相同色温=相同SPD；越低=绝不影响睡眠 |
| Duv/色坐标 | 偏离白光轨迹与光色 | Ra高就无色偏 |
| Ra / R9 | 对应测试条件下的显色评价/饱和红样本表现 | 所有模式均高显色、保护视力或舒适度已验证 |
| Rf/Rg、TLCI | 特定颜色/摄影评价 | 可互换成Ra或人体价值 |
| SPD | 每波长的光谱输出分布 | 单凭漂亮曲线证明眼位剂量、临床结果 |
| mDER | melanopic daylight efficacy ratio，无单位 | 眼位mEDI、褪黑素抑制率、清醒度 |
| mEDI，lx | melanopic EDI，等效D65日光的节律相关眼位光指标 | 人体一定产生的效果或某人已达到健康目标 |
| 波段积分占比 | 定义波段内辐射量相对总辐射量 | 过滤效率、绝对零蓝绿、仪器RGB百分比 |
| PstLM、SVM、调制深度等 | 各自定义下时间光调制特征 | 一个百分比涵盖所有亮度、模式与人群 |

眼位mEDI = 该眼位普通照度 × 该眼位谱形的mDER。
**源端mDER只有谱形在该位置成立时才可参与估算；不能把积分球源端值无条件乘桌面照度，冒充眼位实测。**
mEDI对曝光时间的积分可以描述某种累计光学暴露，仍不是已验证生理“有效剂量”。

## 480nm青光：需求与结论分开

研发要求是日间独立青光补偿、按时段和任务管理，关注2700–6500K混光在480nm附近的连续性。它不是“越多越好”的全天目标。
市场可解释“色温相近，光谱也可能不同”“我们关注实际到眼睛的日间光”。独立通道应有BOM/驱动/光谱证明。
若要说净增益X%，需同产品、版本、实际色点、任务照度、光学、位置、背景和仪器条件的开关A/B；无法全部匹配时说明残余差别。
两条不同产品或不同功率的谱线不能充当前后实验。归一化图说明每相同光通量的谱形分布；绝对图说明实际输出，二者不要混称。
“全范围没有青光缺口”“行业独有”“更清醒X%”分别需要逐档数据、先例检索、人体研究；不能靠一张SPD得到。

## 1800K与1000K

- Desk/Floor的1800K保留任务灯结构，能否继续读写看具体任务照度与光色。
- Halo的1000K和蓝绿抑制属于夜间设计方向；不把通道控制虚构成实体滤光片。
- CCT接近1000K或色点远离白光轨迹时，要核对算法适用性；红光不能只凭文件名定为1000K。
- 暖光照片、屏幕调色、肉眼感觉与源端/眼位光谱是不同证据。
- 不把“无蓝光”与RG0互相推导；检测等级仅按证书型号、条件和范围解释。

## 环境参考值

历史资料引用健康成人日间约≥250 lx mEDI、睡前约≤10 lx等环境建议。[S04/S06/S10]
它们不是产品合格证、疗效阈值或所有人的医嘱。公开引用时回原始共识与适用时间/人群核验；不要机械地给任务灯加睡前10 lx门槛。用户仍读写时先保障任务可用性；任务结束后的低亮环境由相应产品与整间环境共同承担。
中心测点达标不能代表其他位置，也不能忽略窗光、背景灯或另一侧使用者。

## 频闪、安全与认证

低频闪、低蓝光危害、眩光和电气安全分别取证；不要用Ra、CCT、相机无条纹或“看着舒服”相互替代。
拟发布“无频闪”“≤0.5%”“RG0”等，核对具体指标、方法、亮度范围、模式、产品版本和报告。原材料/集团/实验室资质不能自动写成本SKU认证。
对用户用“具体模式下的低时间光调制表现”等有依据表达；不承诺所有敏感人群绝对无不适。

## 一条数据的最小记录

产品/SKU、样品及数量、BOM/固件/配方、名义与实测模式、驱动/功率、摆位与距离、任务面积/点位/探头方向、背景、仪器及日期、单位、计算公式、原始文件、样品/量产适用范围。
文件数不等于样本量，中英文PDF不是独立重复样品。缺项优先补归属和记录，不自动整套重测。
