# 团队可复用交付

## 10分钟新人培训

按下列顺序生成可讲稿，不要求团队背所有指标：
1. 1分钟：品牌从高端自适应照明进入，始于光、不止于光，解决日常位置与时间的用光。
2. 2分钟：Desk/Floor工作与阅读；Halo类环境/夜间；Sound声音；VELA空间香与MORA近身香。
3. 2分钟：讲一个工作到晚间的真实场景，演示当前实物，不虚构全屋联动。
4. 2分钟：解释桌面光与眼位光、CCT与SPD、样品数据与健康效果的不同。
5. 2分钟：练习“自动调光别人也有”“为什么贵”“能改善睡眠吗”“必须用App吗”。
6. 1分钟：按地区价格/交付事实给用户下一步，记录真实拒绝原因。

培训后用实际选型或改写任务检验理解，不用术语问答代替能否销售。

## 证据卡模板

- 用户利益：一句非医疗、场景明确的话。
- 产品与版本：SKU、样品、BOM/固件与测试日期。
- 条件：模式、任务范围、摆位/眼位方向、背景。
- 数字：原值、单位，若有比较给基线、分母和计算。
- 能证明：一句具体结论。
- 不能证明：只列最相关边界。
- 来源：原报告和原始文件入口。
- 对外文案：去掉内部标签，保留理解所需的小字。

示例工作稿：
“晚间继续用眼，有更暖的任务光选项。”
证据：Desk指定样品，标称1800K/100%档，60×40cm九点平均305.08lx、最低110.9lx；中心水平眼位mEDI31.5lx。几何见05。
不得缩写成“全桌300lx、睡前零干扰”。

## PDP输出模板

给：首屏标题/副标题/证据条/CTA；3个场景模块；2–3张证据卡；产品选择；规格与售后；FAQ。
标明每段依赖哪个已确认功能/报告。消费者成稿不放内部不确定性列表；另给短内部备注，明确争议字段如何处理。
参数不完整时先写完整利益与应用稿，规格栏精确标待核，不凭空填齐。

## 销售/招商一页纸

受众与地区 → 一个明确购买问题 → 1–2款产品角色 → 真实图片/演示 → 2–3条可验证差异 → 当前商业事实 → 试点建议 → 下一次评估。
对候选代理不写“已合作”；对待定地区不虚构渠道利润、独家、备货和售后承诺。完整报价需要真实商品和成本，不能用建议数补齐。

## 短视频脚本模板

- 目标用户/场景/一个CTA。
- 前3秒：生活问题或可见差异，不先报头衔、品牌或科学名词。
- 中段：人物做一件事，产品发生一项真实变化，给一个理解支点。
- 证据：需要时用简短准确的条件卡；不把曲线装饰当证明。
- 收尾：用户能做什么，产品处于可买/预售/通知/咨询哪一种。
- 分镜表：时长、画面、台词、真实控制/声源、所需证据与素材。
- 内部备注：曝光一致、尺寸、当前固件、授权、地区商品尾版。

3秒和时长是制作工具，不是保证传播效果。钩子可以锋利，因果必须诚实。

## 科学/技术转市场

输出四列：原始发现或设计 → 与本产品的关联 → 当前可用语言 → 还缺什么。
人体/动物/体外，同行评审/预印本，样品/量产分别写。高质量机制研究也不能直接写成成品已改善健康；阴性与矛盾证据要保留。
需要新增研究时优先原始论文与官方技术资料；不要为宣传寻找单向支持。

## 内容评审

逐项给通过/修改后通过/不通过，并提供直接替代稿：
- 用户理解：谁、哪里、做什么、下一步。
- 产品事实：SKU、控制、地区版本。
- 证据：来源、位置、单位、分母、适用范围。
- 主张：有没有越级。
- 审美：层级、字距行长、对比、真实材质、人物与尺度。
- 商业：价格/交付/售后/CTA是否一致。
不只说“高级感不足”或“有合规风险”，指出具体句子和修法。低影响事实缺项不拖累全部内容。

## 经营复盘

先写本期要决定什么，再用按地区/渠道/SKU拆分的真实漏斗与贡献利润判断。
原始事实、分析、建议分开；曝光/线索/订金/订单/交付/留用不能混加。未知数据写未取得，不反向认定为0。
下一步最多三项最重要动作，给可验收交付；负责人和时间仅沿用已确认安排，新增则标建议。
