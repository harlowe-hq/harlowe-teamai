# 宣称、竞争与销售异议

## 主张证据梯度

| 层级 | 可以承载的内容 | 所需依据 |
|---|---|---|
| 配置事实 | 独立通道、旋钮、传感器、温控、无内置音响 | 当前型号BOM/PRD或可核实实物 |
| 工程表现 | 某模式照度、SPD、显色、眼位mEDI、调光 | 对应版本、条件与报告 |
| 使用体验 | 用户觉得易操作、愿意继续用、购买原因 | 招募、样本、问法、实际行为与授权 |
| 竞争领先 | 在明确场景胜过具体型号 | 官方规格支持该项差异，或匹配横测 |
| 人体结果 | 睡眠、警觉、视力、认知、疼痛、皮肤变化 | 对应成品、使用方案与适当人体研究；不能借外部材料研究代替 |

后一级不能由前一级自动推出。科学机制支持研发方向，不等于证明我们的成品功效。

## 现成替代语言

| 越界或无依据表达 | 准确工作稿 |
|---|---|
| 青光让人更清醒27% | 指定Desk样品两模式任务照度相近，中心眼位mEDI约167与212lx |
| 比普通灯减少95%睡眠干扰 | 本款样品指定日夜模式的眼位mEDI不同；按完整表说明任务照度与位置 |
| 1000K完全不抑制褪黑素 | 为夜间设计深暖光，并控制蓝绿输出；具体模式数据按测试说明 |
| 全色温高显色 | 在指定工作白光模式下，样品Ra/R9为…… |
| AI识别你正在做什么 | 按你选择的任务与作息安排用光 |
| 自动测你的眼位剂量 | 可移动传感器测实际任务位置的光；眼位数据另由实验室测量 |
| 雷达监测睡眠/心率/呼吸 | 按已确认功能描述在场感知 |
| 停止扩香就没有香味 | 停止新增扩香；室内余香仍会随环境变化 |
| 临床级/医用级健康灯 | 按当前认证、产品用途与报告具体描述 |
| 保护视力、治疗老花、改善失眠、抗衰 | 任务照明、日夜光配置、真实使用体验；不替换成同义医疗暗示 |

不将“疗愈”当成绕开证据的词。公开健康、法规或认证解释应按发布地区回到原始研究/官方规则核验，不能把本skill当法律或医学意见。

## 竞争集合与事实边界

以下是S06在2026-11-09的资料归纳，后续型号/规格仍需更新，不能当今日完整竞品数据库。

| 对象 | 应承认的既有能力 | 我们应证明什么 |
|---|---|---|
| Dyson具体型号如CD06 | 有日光相关、任务/环境使用等逻辑 | 当前任务姿态、最低可用色温等逐项差异；无实物只做官方规格比较 |
| Honeywell 02E GEN | 对应资料固定4000K等，限具体型号 | 我方光色选择；不能延伸整个品牌 |
| Honeywell U7 | 已有居家模式、感应/调光等 | 任务可用性、日夜眼位、控制的匹配实测 |
| BenQ等工作/屏幕灯 | 自动补光、屏幕场景已有成熟表达 | 真实任务与时间组合，不称自动补光独有 |
| Hue及智能系统 | 颜色、日程、影院/日落等场景存在 | 低操作负担、实际眼位、出光、家居品质与具体使用 |
| Hatch Restore | 有光声睡前流程 | Halo使用、夜间光谱和操作，不说对方只有音乐 |
| Lumie/Loftie | 有低蓝/红光等夜间设计 | 不以1000K或暖色照片直接宣称领先 |
| 专业去蓝绿灯 | 已有去蓝绿路线 | 日间、夜间、家居形态与使用的组合价值 |
| Signify BioUp等 | 青光增强已有商业先例 | 独立通道的实际配置与匹配收益，不称全球首创 |
| Flos/Artemide/Louis Poulsen/B&O等 | 设计、品牌信任或声音价值 | 功能、尺度与设计的自身证据，不贬低美学、不暗示同等音质 |

团队目前有Honeywell实物、没有Dyson实物[C03]。先用现有设备完成具体对照，不为了写一页PDP就要求买全市场。

## 反对意见：可直接用的回答结构

“别的灯也自动调光。”
答：是的，自动调光已有很多产品。我们建议你看实际工作位置怎么测光、你怎样选任务，以及晚间使用如何安排。接下来用当前实物演示两项已实现的差别。
不要顺手加上未完成偏好学习。

“全光谱不是已经够了吗？”
答：光谱是重要的一部分，还要看它在什么时间、照到哪里、你做什么。我们把工作任务和一天里的变化一起考虑，具体看这一款的实测与使用方式。
不把所有全光谱竞品说成固定输出。

“为什么值这个价？”
答：先看你准备放哪里、替代哪一盏，再看任务光、形态材质、操作和售后。若这些没有对你形成足够价值，就不该只为多一个参数付费。
不要用未来订阅、尚未实现AI或“健康无价”支撑溢价。

“能改善睡眠/保护视力吗？”
答：我们能提供的是这款灯在对应模式下的照度、光谱与使用安排。它有为日间工作和晚间环境设计的功能；目前不能把这些数据说成对每个人的睡眠或视力改善保证。

“我不想装App。”
答：以当前型号实际可用的实体开关、旋钮和离线行为演示；如果某项日程需要设置，就直接说明。不要笼统承诺全系列所有功能无App。

“要把全套都买回去吗？”
答：可以从一个最需要的工作位或晚间位置开始。光、声、香各自成立，其他部分按需要增加。
